# هنرمندشو 🎨

مارکت‌پلیس سفارش نقاشی — ارتباط مشتری‌ها با هنرمندان نقاش ایران.

> **پروژه فریلنسری** — PHP خالص + MySQL (سازگار با Laragon / XAMPP)

---

## امکانات

| بخش | توضیح |
|---|---|
| 🏠 صفحه اصلی | بنر معرفی، دسته‌بندی تکنیک‌ها (رنگ روغن، آبرنگ، سیاه‌قلم، اکریلیک، مداد رنگی، دیجیتال، فانتزی)، جدیدترین آثار گالری، هنرمندان تأییدشده |
| 👩‍🎨 هنرمندان | لیست + فیلتر تخصص/شهر + مرتب‌سازی (جدیدترین، امتیاز، تعداد نظرات) + دکمه علاقه‌مندی ♡ |
| 🖼 گالری آثار (`gallery.php`) | آثار آماده خرید با فیلتر تکنیک و مرتب‌سازی قیمت + افزودن به سبد |
| 🎨 جزئیات اثر (`artwork.php`) | تصویر بزرگ، مشخصات، آثار دیگر همان هنرمند، خرید |
| 👤 پروفایل هنرمند | نمونه‌کار، امتیاز، بیو + **نظرات واقعی مشتری‌ها** + فرم سفارش مستقیم |
| 📝 ثبت پروژه | فرم **۳ مرحله‌ای** (ایده ← جزئیات و بودجه ← اطلاعات تماس) |
| 🛒 سبد خرید | افزودن/حذف آیتم + تسویه و تبدیل به سفارش |
| 📦 پیگیری سفارش | جستجو با کد رهگیری (`HMS-xxxx`) یا شماره سفارش + نمایش مراحل پیشرفت (تاریخ‌ها شمسی) |
| 💬 چت (`chat.php`) | گفت‌وگوی مشتری ↔ هنرمند داخل هر سفارش، با آپلود عکس پیشرفت کار |
| ✅ تأیید پیشنهاد (`bid-accept.php`) | مشتری پیشنهاد هنرمند را قبول می‌کند → سفارش + کد رهگیری + چت خودکار ساخته می‌شود |
| 🎨 پنل هنرمند | پروژه‌های باز، ثبت پیشنهاد، تغییر وضعیت سفارش، **گالری شخصی + آپلود اثر**، **نمودار درآمد ماهانه شمسی** |
| 🛡 پنل مدیریت | تأیید/رد هنرمندان، مدیریت کاربران، وضعیت پروژه‌ها، **صندوق پیام‌های تماس با علامت خوانده‌شده** |
| ⌕ جستجو (`search.php`) | جستجوی سراسری هنرمند/اثر/تخصص از هدر |
| ♡ علاقه‌مندی‌ها | ذخیره هنرمند و اثر (در پروفایل مشتری نمایش داده می‌شود) |
| 🌙 حالت شب | کلید 🌙 در هدر، ذخیره در localStorage |
| ✉️ تماس با ما | ذخیره پیام‌ها در دیتابیس |
| ❤️ احراز هویت | ثبت‌نام (مشتری/هنرمند)، ورود با `password_hash`، سشن امن با `session_regenerate_id` |
| 📅 تاریخ شمسی | همه تاریخ‌ها با هلپر جلالی (`includes/jalali.php`) به فارسی نمایش داده می‌شوند |

## اجرا (Laragon / XAMPP)

1. کل پروژه را در پوشه‌ی روت وب بگذار (مثلاً `C:\laragon\www\freelancerP`).
2. دیتابیس را بساز:
   ```sql
   source database.sql
   source database_v2.sql
   ```
   (یا در phpMyAdmin هر دو فایل `database.sql` و `database_v2.sql` را import کن — نام دیتابیس: `honarmandsho_v2`)
3. اطلاعات اتصال در `config.php` (پیش‌فرض: `127.0.0.1` / `root` بدون رمز).
4. اجرا: `http://localhost/freelancerP/index.php`

### حساب‌های نمونه (رمز همه: `123456`)

| نقش | ایمیل |
|---|---|
| مدیر | `admin@honarmandshoo.ir` |
| هنرمند | `sara@example.com` |
| مشتری | `maryam@example.com` |

> ⚠️ اگر ورود با این حساب‌ها انجام نشد، یعنی هش‌های نمونه قدیمی هستند — کافی است یک بار ثبت‌نام کنی یا هش‌ها را با `password_hash()` دوباره بسازی.

## نکات فنی

- PHP 8+ (از `??`، arrow functions و `match`-friendly syntax استفاده شده)
- PDO با prepared statement در همه کوئری‌ها (ضد SQL Injection)
- خروجی همه‌ی داده‌ها با `e()` (htmlspecialchars — ضد XSS)
- اگر دیتابیس در دسترس نباشد، سایت با **داده‌های نمونه** کار می‌کند (fail-safe)
- رابط کاربری کاملاً **RTL** با فونت وزیرمتن و پالت صورتی/گرم
