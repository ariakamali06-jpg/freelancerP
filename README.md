# هنرمندشو 🎨

مارکت‌پلیس سفارش نقاشی — ارتباط مشتری‌ها با هنرمندان نقاش ایران.

> **پروژه فریلنسری** — PHP خالص + MySQL (سازگار با Laragon / XAMPP)

---

## امکانات

| بخش | توضیح |
|---|---|
| 🏠 صفحه اصلی | بنر معرفی، دسته‌بندی تکنیک‌ها (رنگ روغن، آبرنگ، سیاه‌قلم، اکریلیک، مداد رنگی، دیجیتال، فانتزی)، هنرمندان تأییدشده |
| 👩‍🎨 هنرمندان | لیست + فیلتر تخصص/شهر + مرتب‌سازی (جدیدترین، امتیاز، تعداد نظرات) |
| 👤 پروفایل هنرمند | نمونه‌کار، امتیاز، بیو + **فرم سفارش مستقیم** از همان هنرمند |
| 📝 ثبت پروژه | فرم **۳ مرحله‌ای** (ایده ← جزئیات و بودجه ← اطلاعات تماس) |
| 🛒 سبد خرید | افزودن/حذف آیتم + تسویه و تبدیل به سفارش |
| 📦 پیگیری سفارش | جستجو با کد رهگیری (`HMS-xxxx`) یا شماره سفارش + نمایش مراحل پیشرفت |
| 🎨 پنل هنرمند | مشاهده پروژه‌های باز، ثبت پیشنهاد (bid)، تغییر وضعیت سفارش‌های خودش |
| 🛡 پنل مدیریت | تأیید/رد هنرمندان، مدیریت کاربران، تغییر وضعیت پروژه‌ها |
| ✉️ تماس با ما | ذخیره پیام‌ها در دیتابیس |
| ❤️ احراز هویت | ثبت‌نام (مشتری/هنرمند)، ورود با `password_hash`، سشن امن با `session_regenerate_id` |

## اجرا (Laragon / XAMPP)

1. کل پروژه را در پوشه‌ی روت وب بگذار (مثلاً `C:\laragon\www\freelancerP`).
2. دیتابیس را بساز:
   ```sql
   source database.sql
   ```
   (یا در phpMyAdmin فایل `database.sql` را import کن — نام دیتابیس: `honarmandsho_v2`)
3. اطلاعات اتصال در `config.php` (پیش‌فرض: `127.0.0.1` / `root` بدون رمز).
4. اجرا: `http://localhost/freelancerP/index.php`

### حساب‌های نمونه (رمز همه: `123456`)

| نقش | ایمیل |
|---|---|
| مدیر | `admin@honarmandshoo.ir` |
| هنرمند | `sara@example.com` |
| مشتری | `maryam@example.com` |

> ⚠️ اگر ورود با این حساب‌ها انجام نشد، یعنی هش‌های نمونه قدیمی هستند — کافی است یک بار ثبت‌نام کنی یا هش‌ها را با `password_hash()` دوباره بسازی.

## ساختار پروژه

```
freelancerP/
├── index.php              # صفحه اصلی
├── artists.php            # لیست هنرمندان + فیلترها
├── artist.php             # پروفایل هنرمند + سفارش
├── project-new.php        # ثبت پروژه (۳ مرحله)
├── track-order.php        # پیگیری سفارش
├── cart.php               # سبد خرید و پرداخت
├── profile.php            # پروفایل مشتری
├── artist-dashboard.php   # پنل هنرمند
├── admin.php              # پنل مدیریت
├── login / register / logout.php
├── about.php / contact.php
├── config.php             # اتصال DB + هلپرها + داده‌های دمو
├── database.sql           # اسکیمای کامل + داده نمونه
├── includes/              # header و footer مشترک
├── assets/                # style.css و app.js و تصاویر
└── uploads/               # فایل‌های آپلودی کاربران
```

## نکات فنی

- PHP 8+ (از `??`، arrow functions و `match`-friendly syntax استفاده شده)
- PDO با prepared statement در همه کوئری‌ها (ضد SQL Injection)
- خروجی همه‌ی داده‌ها با `e()` (htmlspecialchars — ضد XSS)
- اگر دیتابیس در دسترس نباشد، سایت با **داده‌های نمونه** کار می‌کند (fail-safe)
- رابط کاربری کاملاً **RTL** با فونت وزیرمتن و پالت صورتی/گرم
